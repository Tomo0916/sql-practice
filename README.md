# SQL Practice

ブラウザだけで動く SQL 練習アプリ（10言語対応）。 https://tomo0916.github.io/sql-practice/

- **index.html** … 学習アプリ（基礎・集計・JOIN の 3章 18レッスン）
- **test.html** … 紙テスト作成（A4 印刷 / PDF 保存）

## 授業での使い方

1. 各レッスンの **例題** はみんなで解く固定問題です。右上の **発表モード** で文字が大きくなり、
   **ステップで解説** を押すと SQL が 1 句ずつ組み上がり、各段階の結果表が表示されます。
2. 続く **演習 1〜5** は、例題と同じ書き方を別のデータ（本・社員・カフェ・映画…）で練習する問題です。
   - 何もしなければ **毎日自動で新しい問題** に入れ替わります（セット番号 = 今日の日付）。
   - **別の問題を作る** を押すと新しいセット番号（例: `K7Q2`）になります。
     この番号を板書するか **リンクをコピー** して配れば、クラス全員が同じ問題になります。
3. 例題 + 演習 3 問を正解するとレッスン完了。記録はブラウザに保存され、言語を切り替えても消えません。

## 紙テスト（PDF）

`test.html` でレッスン・問題数・形式（SQL を書く / 結果を予想 / ミックス）・問題用紙の言語を選び、
**印刷 / PDF保存** → 送信先「PDF に保存」。問題用紙・データ表・解答ページができます。
同じセット番号なら同じテストを何度でも作れます（再印刷・追試に便利）。

## 問題を増やすには

| やりたいこと | 編集するファイル |
|---|---|
| 演習用のテーマ（表）を足す | `js/datasets.js` の `SINGLE_DATASETS`（1表）か `JOIN_DATASETS`（2表）に 1 つ追加 |
| 新しい書き方（レッスン）を足す | `js/lessons.js` の `LESSONS` に 1 つ追加 |
| 画面の文言 | `js/i18n.js`（必ず 10 言語ぶん） |

テーマを 1 つ足すだけで、すべてのレッスンの演習とテストにそのデータが使われます。
数値列（`n1`, `n2`）の値は表の中で重複させないでください（並び替え問題の答えが 1 つに決まるように）。

変更後は必ずチェックを実行してください（翻訳漏れ・日本語の混入・答えが 0 行になる問題などを検出します）:

```
cd tools && npm install && node check.js
```

## ファイル構成

```
index.html / test.html     画面
css/app.css, css/test.css  デザイン（ダークモード・スマホ・印刷対応）
js/i18n.js                 UI 文言（10 言語）
js/datasets.js             すべての表データ
js/lessons.js              レッスン（例題 + 演習の作り方 + 解説ステップ）
js/engine.js               問題生成・採点・SQL 実行（SELECT 以外はブロック）
js/common.js               共通部品
js/app.js, js/test.js      各ページの動き
tools/check.js             自動チェック
groupby.html, join.html    旧ページ → 新アプリへ転送
```
