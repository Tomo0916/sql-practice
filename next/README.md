  - `cd tools-next && node verify-guides.mjs` で、Python ガイドのコードを pandas で実行し、アプリの SQL と同じ数字が出ることを確かめる。

- 復習（終わったレッスンが1・3・7…日後に戻ってくる）、ミックス練習、用語集、ダークモード、文字サイズ、オフライン対応（ホーム画面に追加可）。

## Supabase の設定
1. Supabase のプロジェクトを作り、Authentication → Sign In / Providers で **Allow anonymous sign-ins** をオン。
2. SQL Editor に `supabase/schema.sql` を貼って Run（何度実行しても安全）。**アプリを更新したときも、もう一度 Run してください**（例：タイマーは 2026-10-29 に追加した列と関数を使います）。
3. `config.js` に Project URL と **anon / publishable key** を書く（service_role key は絶対に書かない）。
4. 先生のアカウントは管理者が作ります（画面からの新規登録はできません）:
   - Supabase の Authentication → Users → **Add user** でメールアドレスとパスワードを入れ、**Auto Confirm User** にチェック
   - SQL Editor で先生リストに追加: `insert into public.teachers (email) values ('先生のメール');`
   - 先生を外すとき: `delete from public.teachers where email = '先生のメール';`（そのクラスにも入れなくなります）

先生リストにないアカウントは、ログインできても「先生として登録されていません」と表示され、クラスを作ることも見ることもできません。

安全性：行レベルセキュリティで、生徒は自分の記録だけ、先生は自分のクラスだけ見られます（`tools-next/rls-test.sql` で検証）。
生徒が持つ情報はニックネームと解答記録だけです。

## 問題・文言を増やすには
| やりたいこと | ファイル |
|---|---|
| 演習のテーマ（表）を足す | `js/datasets.js`（足すだけで全レッスンの演習とテストに使われる）。名前は `i18n/*.js` の `ds.<表名>` |
| レッスン（書き方のパターン）を足す | `js/lessons.js` ＋ `i18n/*.js` の `L.<key>.title/point/desc` |
| 文言・翻訳を直す | `i18n/<言語>.js`（1言語1ファイル。やさしい日本語は `{漢字|かんじ}` でふりがな） |

変更したら必ず：`cd tools-next && npm install && node check.mjs`
（全言語の抜け・日本語の混入・ふりがな漏れ・1,080問の答え・穴うめ/ならべかえ・紙テストを自動検査）

公開後に大きく変えたときは `sw.js` の `VERSION` を1つ上げてください（オフライン用キャッシュの更新）。
