# SQL Practice — 次世代版（試用）

公開URL: https://tomo0916.github.io/sql-practice/next/ （生徒用） ・ `…/next/teacher.html`（先生用）

今の版（リポジトリ直下）はそのまま動いています。この `next/` は独立した新しい版です。

## できること

**生徒**
- 1レッスン = 例題 → 穴うめ → ならべかえ（ワナ入り）→ 書いてみよう ×3。演習は毎日／クラスのセット番号ごとに自動生成。
- まちがいの種類に合わせた説明（全角文字・引用符・列名のつづり・句の順番・ASC/DESC の逆 など）。エラー位置に波線。
- 例題のステップ解説：SQLが1句ずつ組み上がり、「書く順番」と「実行される順番」、JOIN の行のつながりを図で表示。
- 11言語（日本語・やさしい日本語〈ふりがな付き〉・英語・ネパール語・フランス語・ミャンマー語・ベンガル語・シンハラ語・インドネシア語・ベトナム語・中国語）。2つめの言語を小さく併記できる。言語を変えても記録は消えない。
- 復習（終わったレッスンが1・3・7…日後に戻ってくる）、ミックス練習、用語集、ダークモード、文字サイズ、オフライン対応（ホーム画面に追加可）。
- クラスコード（またはQR）とニックネームだけでクラスに参加。メール不要。

**先生**（`teacher.html`、メール＋パスワード）
- クラス作成・QR表示・参加受付の停止。
- 課題：今日のレッスン、セット番号、模範解答の表示ルール（2回まちがえたら／正解したら／いつでも／表示しない）。保存すると生徒の画面にすぐ反映。
- ライブ：生徒×問題の表がリアルタイムで更新。問題ごとの正解率。
- よくある間違い：まちがったSQLを人数順にまとめ、理由も表示（名前なしでそのまま投影可）。
- 授業で見せる（発表モード）、紙テスト（A版/B版、11言語、併記、解答・データ表付き → PDF）。
- 教科書（`teacher.html#/book`、ログイン不要）：A4 で印刷。11言語＋併記。ページ番号は固定で、生徒のレッスン画面に「教科書 p.N」と表示される。
  - p.1 表紙（No.・名前欄）、p.2 目次、p.3 基本ルール、p.4 実行される順番（FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT で実際のデータが絞られていく図）、p.5 例題の表、p.6〜23 レッスン1〜18、p.24〜 用語集。
  - レッスンのページ：ポイント／書き方／例題と考え方／結果／よくある間違い（✕まちがったSQL → 実行するとどうなるか → 理由 → ○正しいSQL）／メモ欄。
  - よくある間違いは `js/book-data.js` の `MISTAKES` に SQL で書く。`tools-next/check.mjs` が、まちがったSQLが本当にエラーか違う結果になるかを確認する。説明文は各言語の `book.mx.<id>`。
  - 言語によって1ページに入りきらないときは、そのページだけ自動で少し縮小して1枚に収める（印刷するブラウザで測る）。
  - レッスンを増やすと用語集のページ番号はずれる。印刷済みの教科書がある場合は、新しいレッスンを最後に追加すると既存のページ番号が変わらない。

## Supabase の設定
1. Supabase のプロジェクトを作り、Authentication → Sign In / Providers で **Allow anonymous sign-ins** をオン。
2. SQL Editor に `supabase/schema.sql` を貼って Run（何度実行しても安全）。
3. `config.js` に Project URL と **anon / publishable key** を書く（service_role key は絶対に書かない）。
4. 先生のアカウントは管理者が作ります（画面からの新規登録はできません）:
   - Supabase の Authentication → Users → **Add user** でメールアドレスとパスワードを入れ、**Auto Confirm User** にチェック
   - SQL Editor で先生リストに追加: `insert into public.teachers (email) values ('先生のメール');`
   - 先生を外すとき: `delete from public.teachers where email = '先生のメール';`（そのクラスにも入れなくなります）

先生リストにないアカウントは、ログインできても「先生として登録されていません」と表示され、クラスを作ることも見ることもできません。

安全性：行レベルセキュリティで、生徒は自分の記録だけ、先生は自分のクラスだけ見られます（`tools-next/rls-test.sql` で検証）。
生徒が持つ情報はニックネームと解答記録だけです。

## 問題・文言を増やすには
| やりたいこと | ファイル |
|---|---|
| 演習のテーマ（表）を足す | `js/datasets.js`（足すだけで全レッスンの演習とテストに使われる）。名前は `i18n/*.js` の `ds.<表名>` |
| レッスン（書き方のパターン）を足す | `js/lessons.js` ＋ `i18n/*.js` の `L.<key>.title/point/desc` |
| 文言・翻訳を直す | `i18n/<言語>.js`（1言語1ファイル。やさしい日本語は `{漢字|かんじ}` でふりがな） |

変更したら必ず：`cd tools-next && npm install && node check.mjs`
（全言語の抜け・日本語の混入・ふりがな漏れ・1,080問の答え・穴うめ/ならべかえ・紙テストを自動検査）

公開後に大きく変えたときは `sw.js` の `VERSION` を1つ上げてください（オフライン用キャッシュの更新）。
